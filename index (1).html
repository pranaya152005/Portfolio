Lab Projects

01 · Network Scanning & Enumeration
nmap · kali linux

Practiced network scanning using Nmap to identify open ports and services on target machines in a lab environment.

  • Performed OS detection and service version analysis
  • Identified open ports and running services across scanned hosts
  • Interpreted scan results to assess potential attack surface
Key takeaway: Reconnaissance is the first stage of a penetration test — scan output maps directly to real vulnerabilities.

nmap -O
02 · Web Application Security Testing
burp suite · DVWA

Tested a deliberately vulnerable web application (DVWA) using Burp Suite to identify common web vulnerabilities.

  • Identified Cross-Site Scripting (XSS) vulnerabilities
  • Identified SQL Injection vulnerabilities
  • Used Burp Suite to intercept and analyze HTTP requests
Key takeaway: Practical understanding of the OWASP-style vulnerabilities that Burp Suite and manual testing can uncover in web apps.
burpsuite — DVWA
03 · Packet Analysis using Wireshark
wireshark

Captured and analyzed live network traffic in a lab setup to understand protocol-level communication.

  • Captured network traffic during a simulated FTP authentication sequence
  • Observed local network discovery through ARP resolution and IPv6 router solicitations
  • Analyzed TCP handshakes and unencrypted FTP packets to trace cleartext credential exchange
Key takeaway: Reading packet captures reveals service banners, session state, and insecure protocol practices worth auditing.
